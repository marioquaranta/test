# Better Together - versione per smartphone a schermo compatto

Questionario basato sul Word (5), con tutte le batterie a un item per pagina.

- Banner viola ridotto durante le domande, logo sempre visibile in alto.
- Footer duplicato nascosto solo durante le domande; presente sulla pagina iniziale e finale.
- Spaziature ottimizzate, area di selezione almeno 44 px e carattere leggibile.
- Domande, risposte, codici, filtri ed esportazione CSV invariati.
- Desktop e smartphone utilizzano lo stesso formato di risposta.

**Limite fisico:** su telefoni con schermi molto bassi, oppure nelle domande con molte categorie (es. D1R), non e possibile mostrare tutte le risposte senza scorrimento mantenendo etichette intere e pulsanti leggibili. Non vengono nascoste o divise le categorie.

**GitHub:** sostituire `styles.css` e `app.js` (gli altri file rimangono identici alla versione precedente).

La raccolta dei dati centralizzata non e attiva; e un sito di prova.
